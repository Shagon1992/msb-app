Install Aplikasi MSB

Install aplikasi ini di layar utama HP kamu untuk akses lebih cepat dan tampilan seperti aplikasi native.

1. Ketuk tombol Bagikan (Share) di Safari.
2. Gulir ke bawah dan pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
3. Ketuk Tambah di pojok kanan atas.
